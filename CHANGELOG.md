# Changelog

## 4.0.0 - Independent MWC rebuild

- Rebuilt Save Slots around an independent MWC-specific codebase while keeping existing profiles, settings, and folders compatible.
- Added a native-looking `SAVES` entry to the My Winter Car main menu and refreshed the three-profile screen.
- Strengthened profile switching, deletion backups, rollback, and safe-mode recovery.
- Improved profile information, thumbnail handling, performance, and diagnostics.
- Made the save screen clearer for first-time players and added a quiet camera sound to profile transitions.
- Improved player-name display, card readability, menu sizing, native-style button motion, and quiet click feedback.
- Added the square compact-disc ModLoader icon and the monochrome default image for saves without screenshots.
- Removed the legacy MSC-derived implementation and UI bundle from the release.

## 3.0.0 - Save safety update

- Added verified save switching, emergency backups, rollback, and safe mode.
- Improved empty-slot handling, Continue-button behaviour, thumbnails, and folder shortcuts.

## 2.0.0 - MWC compatibility update

- Added Corris trim information and moved profiles into the dedicated `SaveSlotsMWC` folder.
- Improved save-folder compatibility, menu behaviour, backups, and diagnostics.

## 1.0.0 - Beta

- First My Winter Car release with three save profiles, thumbnails, shared options, and emergency backups.
