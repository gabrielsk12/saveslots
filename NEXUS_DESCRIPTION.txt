SAVE SLOTS MWC 4.0.0

Save Slots gives My Winter Car three independent save profiles from a purpose-built 90s MWC-themed SAVES screen.

FEATURES
- Save1, Save2, and Save3 with horizontal cards and screenshots
- Player name, Corris trim, money, mortality, location, and last-played information
- Selected and empty states, deletion confirmation, and Continue/New Game synchronization
- SAVES entry that uses MWC's installed Continue-button presentation at runtime, so it belongs with the other main-menu choices
- Simple late-90s MWC profile screen with deep navy and cold-blue panels, ice-white borders, cyan labels, orange state controls, and three save columns
- Staggered card entrance, mechanical panel reveal, native-style hover/press response, quiet UI feedback, and a segmented switch transition
- Nested save data, synchronized options, optional editor backups, and emergency backups
- Automatic/manual/custom screenshots and four date formats
- Supplied monochrome fallback image whenever a profile has no screenshot
- Transactional staging, verification, critical-file SHA-256 checks, rollback, and safe mode
- Verified recovery backup before every non-empty deletion, retained separately for each Save1-Save3 profile
- Existing SaveSlotsMWC folders and setting IDs remain compatible
- Existing active saves are copied into selected Save1 on first install and shown automatically
- `saveslots` / `ss` console diagnostics for status, UI recovery, refresh, backup-folder access, and logs

INSTALL
1. Install MSCLoader for My Winter Car.
2. Put SaveSlots.dll in the Mods folder.
3. Start the game and use SAVES on the main menu.

UPGRADING
Replace the previous SaveSlots.dll. Do not delete the SaveSlotsMWC folder. Version 4 reads existing Save1-Save3 profiles, options, backups, markers, manifests, and PNG/JPG thumbnails.

INDEPENDENT REWRITE AND ASSET POLICY
Version 4 uses the independent MwcSaveSlots C# architecture and constructs its profile UI at runtime from Unity UI primitives. The SAVES entry copies the presentation of the installed MWC Continue button at runtime; no game menu asset is redistributed. The DLL includes no code, prefab, asset bundle, font bytes, dummy thumbnail, shutter clip, or serialized script reference from Athlon's My Summer Car Save Slots mod. The legacy MWC bundle was excluded after an audit found exact MSC objects inside it.

The menu can use FugazOne-Regular because it requests the font already loaded by My Winter Car; the mod does not redistribute that font. The packaged media are the square compact-disc icon, the supplied monochrome fallback thumbnail, and Unity-compatible PCM conversions of a camera transition sound by Pixabay creator irinairinafomicheva and a UI click by DenielCZ. Both sounds use the Pixabay Content License and play at restrained volumes. A small procedural transition sound is used only if Unity cannot decode the camera WAV.

SAFETY
Switching is serialized. The current profile is mirrored, an emergency backup is verified, the requested profile is staged and verified, the active directory is swapped, and only then is the selected marker committed. A pre-commit failure rolls back and enables SafeMode.txt.

Deleting a non-empty profile first creates and verifies a recovery copy in `EmergencyBackups\DeletedProfiles\Save1..3`. The profile is then moved atomically out of service before cleanup. A failed move restores the original folder. At least the newest deleted backup for each slot is retained, even when the normal emergency-backup rotation is set to one.

RUNTIME COMPATIBILITY
Compiled against the framework assemblies shipped with My Winter Car. Verified against MWC Steam build 23268598, Unity 5.0.0f4, Unity Mono 2.0.5, and MSCLoader 1.4.2.410.

DIAGNOSTICS
Use `saveslots status` in the MSCLoader console to print the selected profile, safe-mode state, UI hierarchy, and current visibility suppression reason. Other safe commands: `show`, `open`, `close`, `refresh`, `backups`, `log`, and `help`. Alias: `ss`.
